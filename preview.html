🔬 What changed in the 2025 modernization (and what to do)

Markup fields

Legacy wrapped text with hard line-breaks; new pipeline serves clean Markdown. Same words, different whitespace (proven on NCT04852770: 1,629 vs 1,647 chars, identical once normalized). Do: pin markupFormat explicitly and normalize whitespace before diffing.

Locations + maps

Geography now comes from a new place database. A 50-mile search around Washington, DC correctly returns NCT01181323 and NCT00002359 with city/country lists. Do: request location pieces explicitly; re-validate any old latitude/longitude joins.

Pagination contract

Keep paging while nextPageToken is present; stop when it disappears. Asking for 1,001 rows returns 1,000 with no error (silent cap). Nonsense queries return an empty list with success — that is a real answer, not a bug.
